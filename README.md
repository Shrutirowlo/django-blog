# django-blog
# Django Blog Website 🚀

Live Demo: https://shrutirowlo.pythonanywhere.com

## Features
- User Authentication (Login/Register)
- Blog Creation
- Categories
- Search Functionality
- Admin Dashboard

## Tech Stack
- Django
- HTML, CSS, Bootstrap
- SQLite


## How to Run Locally
```bash
git clone https://github.com/Shrutirowlo/django-blog.git
cd django-blog
pip install -r requirements.txt
python manage.py runserver
